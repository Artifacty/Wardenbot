# Wardenbot 1.2

Discord-бот для русскоязычного сообщества Варденов в Foxhole: проверка игроков,
клановые операции, быстрые группы, временные голосовые комнаты, приватные обращения модерации
и автоматически обновляемая карта войны в канале сводки.
Стек: Python 3.13, discord.py, SQLite.

- [Запуск на Windows и Ubuntu](wardenbot/README.md)
- [Обновление до 1.0 и проверка перед открытием](wardenbot/docs/RELEASE_1_0.md)
- [История разработки](wardenbot/docs/DEVELOPMENT.md)
- [Карта войны: запуск и диагностика](wardenbot/docs/WAR_MAP.md)

Реальные разрешения Discord
проверяются на вашем сервере по инструкции релиза. Одна установка с отдельными токеном и БД
рассчитана на один рабочий Discord-сервер; полный набор функций нескольких независимых серверов
в одной БД не поддерживается.
