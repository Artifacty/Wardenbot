# Wardenbot

Discord-бот для совместных операций игроков Foxhole на стороне Варденов.
Стек: Python, discord.py, SQLite. Исходники, тесты и инструкции запуска находятся
в [wardenbot/](wardenbot/README.md).

Разработка идёт небольшими проверяемыми этапами для закрытого теста с 5–7 кланами.
Текущее состояние и оставшиеся задачи: [план разработки](wardenbot/docs/DEVELOPMENT.md).
